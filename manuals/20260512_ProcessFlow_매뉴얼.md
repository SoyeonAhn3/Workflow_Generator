## 1. 개요

ProcessFlow는 조직 내 반복되는 업무 프로세스(월 마감, 예산 검토, 원가 배부 등)를 체계적으로 문서화하는 웹 애플리케이션입니다. 부서를 정의하고, 관련 프로세스를 그룹으로 묶고, 각 프로세스를 메타데이터(화면명, 담당 부서, 처리 시간, 로직, 주의사항, 스크린샷)가 포함된 단계로 분해한 뒤, 서식이 적용된 Word(.docx) 파일로 내보낼 수 있습니다.

| 항목 | 내용 |
|---|---|
| 플랫폼 | 웹 브라우저 (Chrome 권장) |
| 기술 스택 | React 19 + Vite 8 |
| 데이터 저장 | 브라우저 localStorage (텍스트) + IndexedDB (이미지) |
| 출력 형식 | Word (.docx) |
| AI 기능 | Anthropic Claude API (선택 사항) |
| 배포 | Netlify |
| 인터넷 연결 | 최초 접속 시 필요 (AI 기능 사용 시 필수) |

## 3. 시작하기

1. 웹 브라우저에서 배포된 URL에 접속합니다
2. 좌측 사이드바에서 부서를 추가합니다
3. 부서를 선택하면 프로세스 그룹 목록 화면(LV2)으로 이동합니다
4. 그룹을 추가하고, 그룹 내에 프로세스를 추가합니다
5. 프로세스를 클릭하면 단계 편집 화면(LV3)으로 이동합니다
6. 단계를 추가하고 상세 정보를 입력합니다
7. 완성 후 Word 내보내기 버튼으로 문서를 생성합니다

## 4. 주요 기능

### 4.1 부서 관리 (LV1)

부서를 추가, 편집, 삭제합니다. 좌측 사이드바에서 부서 목록을 관리합니다.

| 동작 | 방법 | 결과 |
|---|---|---|
| 부서 추가 | 사이드바 `+ 부서 추가` 클릭 | 새 부서 생성 |
| 부서 선택 | 부서명 클릭 | LV2 화면으로 이동 |
| 부서 삭제 | 삭제 버튼 클릭 | 하위 그룹/프로세스/단계 전체 삭제 |

> ⚠️ **주의:** 부서를 삭제하면 하위의 모든 그룹, 프로세스, 단계가 함께 삭제되며 복구할 수 없습니다.

---

### 4.2 프로세스 그룹 관리 (LV2)

부서 내 프로세스를 그룹으로 묶어 관리합니다.

| 동작 | 방법 | 결과 |
|---|---|---|
| 그룹 추가 | `+ 그룹 추가` 클릭 | 새 그룹 카드 생성 |
| 프로세스 추가 | 그룹 카드 내 `+ 추가` 클릭 | 방법 선택 모달 표시 |
| 그룹 편집 | 그룹 헤더 편집 버튼 클릭 | 그룹명/설명 수정 |
| 프로세스 선택 | 프로세스명 클릭 | LV3 화면으로 이동 |

---

### 4.3 단계 편집 (LV3)

프로세스의 단계를 추가하고 상세 정보를 입력합니다.

| 항목 | 설명 | 필수 여부 |
|---|---|---|
| 단계명 | 업무 단계의 이름 | 필수 |
| 화면명 | 사용하는 시스템/화면 이름 | 선택 |
| 담당 부서 | 해당 단계 수행 부서 | 선택 |
| 처리 시간 (PT) | 예상 처리 시간 | 선택 |
| 로직 | 상세 처리 방법/절차 | 선택 |
| 주의사항 | 경고 또는 유의사항 | 선택 |
| 스크린샷 | 화면 캡처 이미지 (여러 장 가능) | 선택 |

---

### 4.4 AI 프로세스 자동 구조화

자유 텍스트로 업무 흐름을 설명하면, AI가 자동으로 단계 구조를 생성합니다.

| 단계 | 동작 | 결과 |
|---|---|---|
| 1단계 | 프로세스 추가 시 `✨ AI 자동 생성` 선택 | AI 입력 모달 표시 |
| 2단계 | 프로세스명 + 업무 흐름 텍스트 입력 → `AI로 구조화` 클릭 | Claude API 호출, 분석 중 표시 |
| 3단계 | 생성된 단계 미리보기 확인 → `편집기에서 열기` 클릭 | LV3에 단계 자동 추가 |

> ⚠️ **주의:** AI 기능은 Anthropic API 키가 설정되어 있어야 사용할 수 있습니다. AI가 생성한 단계는 초안이므로 반드시 검토 후 사용하세요.

---

### 4.5 다이어그램 보기

프로세스 단계를 시각적 다이어그램으로 확인합니다.

| 다이어그램 유형 | 설명 | 용도 |
|---|---|---|
| Linear Flow | 단계를 순서대로 직선 배치 | 전체 흐름 한눈에 파악 |
| Swim Lane | 부서별 레인으로 분리 배치 | 부서 간 업무 이동 시각화 |

---

### 4.6 Word 내보내기

프로세스 그룹을 서식이 적용된 Word(.docx) 파일로 내보냅니다.

| 항목 | 설명 |
|---|---|
| 내보내기 단위 | 프로세스 그룹 단위 |
| 포함 내용 | 표지, 프로세스별 단계 표, 스크린샷 |
| 이미지 처리 | Base64 → ArrayBuffer 변환 후 실제 이미지 삽입 |
| 파일 형식 | .docx (Word 2007+) |

---

### 4.7 드래그 앤 드롭 정렬

단계의 순서를 드래그 앤 드롭으로 변경합니다.

| 동작 | 방법 | 결과 |
|---|---|---|
| 순서 변경 | 단계 카드를 드래그하여 원하는 위치로 이동 | 순서 자동 반영 및 저장 |
| 병렬 단계 | 동일 위치에 병렬 분기 설정 | Swim Lane에서 병렬 표시 |

## 5. 데이터 저장 방식

- 텍스트 데이터(부서, 그룹, 프로세스, 단계 정보)는 브라우저의 **localStorage**에 저장됩니다
- 이미지 데이터(스크린샷)는 브라우저의 **IndexedDB**에 저장됩니다
- 별도의 서버나 데이터베이스를 사용하지 않으므로, 데이터는 해당 브라우저에만 존재합니다
- 브라우저 데이터를 삭제하면 모든 데이터가 사라집니다

---

## 6. 주의사항 및 제한사항

> ⚠️ 브라우저 데이터(캐시/쿠키) 삭제 시 모든 프로세스 데이터가 영구 삭제됩니다. 중요한 데이터는 반드시 Word로 내보내기하여 백업하세요.

> ⚠️ 인증/로그인 기능이 없으므로, 해당 브라우저에서만 데이터에 접근할 수 있습니다.

> ⚠️ AI 기능 사용 시 인터넷 연결이 필수이며, API 키가 설정되어 있어야 합니다.

> ⚠️ 모바일에서도 사용 가능하나, 데스크탑 브라우저에서 최적의 경험을 제공합니다.

> ⚠️ 부서/그룹/프로세스 삭제 시 하위 항목이 모두 함께 삭제되며 복구할 수 없습니다.

## 7. 문제 해결 (FAQ)

**Q. 브라우저를 닫았다가 다시 열면 데이터가 사라졌습니다.**
A. 브라우저 설정에서 "종료 시 데이터 삭제" 옵션이 활성화되어 있는지 확인하세요. 해당 옵션이 켜져 있으면 localStorage와 IndexedDB가 초기화됩니다.

**Q. AI 자동 생성 버튼이 동작하지 않습니다.**
A. Anthropic API 키가 환경변수에 설정되어 있는지 확인하세요. Netlify Dev로 실행 시 `.env` 파일에 `ANTHROPIC_API_KEY`가 필요합니다.

**Q. Word 내보내기 시 이미지가 포함되지 않습니다.**
A. 단계에 이미지가 첨부되어 있는지 확인하세요. 이미지는 IndexedDB에 저장되므로, 브라우저 데이터가 삭제되었으면 이미지도 함께 사라집니다.

**Q. 다른 컴퓨터에서 동일한 데이터를 보고 싶습니다.**
A. 현재 서버 동기화 기능은 지원되지 않습니다. Word 내보내기로 문서를 백업하여 공유하세요.

**Q. AI가 생성한 단계 구조가 부정확합니다.**
A. AI 결과는 초안입니다. `다시 입력` 버튼으로 업무 흐름 설명을 더 구체적으로 수정하여 재시도하거나, 편집기에서 수동으로 수정하세요.
